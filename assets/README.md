# Screenshot Checklist

Put your README screenshots in this folder.

Use these exact names:

- `app.png` - main app screenshot
- `python-path.png` - Python installer with "Add Python to PATH" highlighted
- `ffmpeg-install.png` - terminal after `winget install ffmpeg`
- `download-project.png` - GitHub green Code button or Download ZIP menu
- `pip-install.png` - successful `pip install -r requirements.txt`
- `app-launch.png` - app opened after `python main.py`
- `spotify-link.png` - Spotify copy-link menu
- `download-demo.png` - app downloading songs

The README already points to these files.
